Install Gage

You’ll need licensed SOLIDWORKS 2026 with standard part and assembly templates, 64-bit PowerShell 7, and .NET Framework 4.8.1.

  1. Extract the entire ZIP to a local folder. The full guide is in START-HERE.md.
  2. Let any running Gage job finish, save your work, and close SOLIDWORKS.
  3. In the extracted folder, right-click Install-Gage.cmd and choose Run as administrator using your usual Windows account.
  4. Review the installation checks. Type INSTALL and press Enter to register the add-in.

First launch

Reopen SOLIDWORKS. On the right, click the task pane tab labeled SolidWorksAI. The panel opens with the Gage logo. Use the Settings gear to connect Codex or enter an OpenAI project API key.

Choose Design a mounting plate to fill the message box with an editable example. Send it, then review the dimensions before choosing Approve and build.

Common questions

How does Gage work?

Describe the part, assembly, or change you want in the Gage panel. Gage asks for any missing details and prepares a CAD plan for you to review. Once you approve it, Gage carries out the plan in SOLIDWORKS, where you can inspect and edit the result.

What do I need to run Gage?

You’ll need a compatible local SOLIDWORKS installation and either Codex access or an OpenAI project API key.

In Gage’s Settings, select Connect OpenAI account… to use your Codex allowance, or Use OpenAI API key… to bill planning to your OpenAI API project.

Simulation also requires the relevant SOLIDWORKS Simulation license.

Can I download Gage?

Download Gage for Windows and follow the installation steps to add it to SOLIDWORKS 2026.

How should I check generated files?

Use disposable copies while evaluating a workflow. Check dimensions, mates, drawing references, and simulation inputs before relying on the results. Recovery from a crash during a native save remains unverified.
