Common questions

How does Gage work?

Describe the part, assembly, or change you want in the Gage panel. Gage asks for any missing details and prepares a CAD plan for you to review. Once you approve it, Gage carries out the plan in SOLIDWORKS, where you can inspect and edit the result.

What do I need to run Gage?

A compatible local SOLIDWORKS installation and Codex access. Codex access and usage limits follow your account. Simulation also requires the relevant SOLIDWORKS Simulation license.

Can I download Gage?

No public installer is available. Code signing and acceptance testing on an independent clean Windows machine are pending. Request a demo to see Gage in SOLIDWORKS.

How should I check generated files?

Use disposable copies while evaluating a workflow. Check dimensions, mates, drawing references, and simulation inputs before relying on the results. Recovery from a crash during a native save remains unverified.
