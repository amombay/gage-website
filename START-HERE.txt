GAGE WEBSITE — EASY GITHUB PAGES DEPLOYMENT
=============================================

This package has index.html at the TOP LEVEL, so it does not require a custom
GitHub Actions workflow to become a live site.

1. UNZIP this package.
2. Go to https://github.com/amombay/gage-website
3. Upload THE FILES AND FOLDERS INSIDE the unzipped folder.
   The repository root MUST contain index.html, styles.css, script.js,
   config.js, privacy.html, and assets/ (not another parent folder).
4. Go to Settings > Pages.
5. Under Build and deployment choose:
      Source: Deploy from a branch
      Branch: main
      Folder: /(root)
   Save.
6. Open https://amombay.github.io/gage-website/

IMPORTANT: This method works EVEN IF the hidden .github/ folder was not uploaded.
An optional Actions workflow is also included in .github/workflows/deploy.yml,
but you DO NOT NEED IT when using 'Deploy from a branch'.

NOTE: The beta form prepares an email until you add a Formspree endpoint in
config.js. It does not automatically store signups without configuration.

For full setup, details, and checks see README.md.
